
# Project Documentation: AWS Global Content Delivery

## 1. Objective

To deploy a static website on AWS and configure a content delivery architecture using Amazon CloudFront, an Application Load Balancer, and multiple EC2 web servers across different Availability Zones.

## 2. Infrastructure Setup

### EC2 Web Servers
- Launched Amazon Linux 2023 EC2 instances.
- Installed and configured Apache HTTP Server.
- Deployed the Lantern River static website.
- Created an AMI from the configured EC2 instance.
- Launched a second EC2 instance using the AMI.

### Application Load Balancer
- Created an internet-facing Application Load Balancer.
- Configured an HTTP listener on port 80.
- Created a target group named `lantern-river-tg`.
- Registered both EC2 instances.
- Configured HTTP health checks using the `/` path.
- Verified that both targets were healthy.

### Amazon CloudFront
- Created a CloudFront distribution.
- Configured the Application Load Balancer as the origin.
- Configured the origin connection to use HTTP.
- Tested website delivery through the CloudFront distribution.
- Verified website access from multiple devices.

## 3. Deployment Architecture

- AWS Region: Asia Pacific (Mumbai)
- Region Code: `ap-south-1`
- Availability Zones: `ap-south-1a` and `ap-south-1b`
- Web Servers: 2 EC2 instances
- Load Balancing: Application Load Balancer
- Content Delivery: Amazon CloudFront

## 4. Testing and Validation

The following checks were completed:

- Website loaded successfully through the EC2 web server.
- Both EC2 instances were registered with the target group.
- Both target group health checks reported healthy.
- Website access through the ALB DNS was verified.
- Website access through the CloudFront distribution was verified.
- CloudFront delivery was tested from multiple devices.

## 5. Key Learnings

- Deploying static websites on Amazon EC2.
- Creating and using Amazon Machine Images.
- Distributing traffic across multiple Availability Zones.
- Configuring Application Load Balancer listeners and target groups.
- Understanding target group health checks.
- Configuring CloudFront with a custom origin.
- Understanding the relationship between CloudFront, ALB, and EC2.
